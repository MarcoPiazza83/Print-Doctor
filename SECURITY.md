# Security

If you find a security problem in Print Doctor (for example a way to leak API keys or tokens, or to make the plugin change settings outside its safety limits), please **do not open a public issue**.

Use **Report a vulnerability** in the [Security tab](https://github.com/MarcoPiazza83/Print-Doctor/security/advisories/new), or write to **info@meshdab.com**, with a description and, if you can, the steps to reproduce it. You will get an answer as soon as possible, and the fix will be released before the details are made public.

Only the latest version of Print Doctor receives security fixes.
